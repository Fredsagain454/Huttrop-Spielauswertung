# Spielauswertung

Handball-Spielauswertung als Web-App (Erfassen, Auswertung, Bericht, Saison).

Installation auf iPhone/iPad: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
Installation auf Android: Seite in Chrome öffnen → Menü → „App installieren“.

Alle Spieldaten bleiben auf dem jeweiligen Gerät gespeichert – in diesem Repository liegen nur die App-Dateien.
